# 阿B听书 车机版 v1.3.0

面向**安卓横屏车机 / 车载中控屏 / 大屏盒子**的专门构建版本。

## 本版本新增

### 车机 / 大屏适配（设置 → 系统设置 → 车机 / 大屏适配）

- **显示界面上下边距：0–100 px 可调**
  顶部和底部独立调节，单位是**屏幕物理像素**——直接对照车机状态栏截图的高度填数字即可，不用换算 dp。
  车机状态栏多为悬浮覆盖在应用之上，系统拿不到 inset，这个留白就是用来把被压住的按钮「让」出来。
- **界面缩放：60%–160% 可调**
  - 缩小：布局视口同步收缩，网格列数真正重排，一屏能放下更多内容；
  - 放大：按钮在屏幕上物理变大，车机远距离观看、点按容错更高。
  - 实现上用的是「收缩布局视口 + 变换放大还原」，不是简单拉伸，
    **触摸命中与视觉位置始终一致**，不会出现「按钮看得见却点不到」。
- **一键预设**：避开状态栏（上 48px / 下 24px）、紧凑模式（85%）、远距离放大（130%）、恢复默认
- **锁定横屏**：车机固定安装时打开，竖屏误触也不会转屏
- **沉浸式全屏**：隐藏系统状态栏，比手动留边距更彻底
- 所有设置**立即生效并自动保存**，播放页顶栏也有快捷入口（图标按钮），就地就能调

### 车机版构建通道

```bash
./tool/build_car.sh                    # 车机版 release APK
flutter build apk --release --dart-define=ABTS_CAR=1
```

车机版与手机版**包名不同，可同时安装在一台设备上，互不覆盖**：

| | 手机版 | 车机版 |
| --- | --- | --- |
| 包名 | `dev.pages.abts` | `dev.pages.abts.car` |
| 应用名 | 阿B听书 | 阿B听书车机版 |
| 默认方向 | 跟随系统 | 锁定横屏 |

> 本仓库（`DrSkyFree/abts_car`）为车机版专属仓库，Releases 中的安装包均为车机版。

- 应用名显示为「阿B听书车机版」，与手机版一眼可区分
- 车机多为定制 ROM、可能没有 Google 服务；本应用**不依赖 GMS**，可正常运行

## 装完后的第一步

进入 **我的 → 系统设置 → 车机 / 大屏适配**：

1. 先开「沉浸式全屏」——能隐藏的状态栏先隐藏掉；
2. 仍有遮挡时，用上下边距补足：截图看按钮被压住的像素高度，往对应方向填同样的数字；
3. 内容显示不全或字太小，把界面缩放往上调；字太大点不准就往下调。

调好立即生效，无需重启。

## 技术实现

适配层挂在 `MaterialApp.builder` 上，全局统一生效，结构为「**边距在外、缩放在内**」：

```
Padding(上/下边距，物理像素 → 逻辑像素)
└── SizedBox(外层尺寸 w×h)
    └── OverflowBox(紧约束 innerW×innerH)   ← 强制按缩小后的视口布局
        └── Transform.scale(scale)            ← 绘制时放大回 w×h
            └── MediaQuery(size ÷ scale, dpr × scale, inset ÷ scale)
                └── 整棵应用树
```

三个容易踩坑的点（已用测试固定）：

1. `devicePixelRatio` 要**乘** `scale`——除会让按物理像素计算的组件算出一半的值；
2. `MediaQuery` 的 `padding` / `viewPadding` / `viewInsets` **全部是逻辑像素**，
   内层要**除以** `scale`，否则 `SafeArea` 会双重留白；
3. **不能因 `scale == 1` 就跳过缩放容器**——边距在 Padding 层扣除，
   只有缩放容器内部会覆写 `MediaQuery.size` 为「扣边距后的可用区」。
